# Book and Coffee Models

Two Python classes built with test-driven development.

## Book
- Attributes: `title`, `page_count` (must be an integer)
- Method: `turn_page()` prints a message

## Coffee
- Attributes: `size` (Small, Medium or Large), `price`
- Method: `tip()` prints a message and adds 1 to the price

## Run the tests
pipenv install

pipenv shell

pytest -x
